# MicroLab IoT

Maqueta de una plataforma web especializada en **microcontroladores, electrónica, automatización e Internet de las Cosas (IoT)**.

## 🚀 Demo
Proyecto preparado para publicarse con **GitHub Pages**.

## 🧩 Contenido
- Landing page responsive
- Proyectos de IoT y electrónica
- Arduino, ESP32, ESP8266 y Raspberry Pi
- Diseño oscuro con estética tecnológica
- HTML, CSS y JavaScript puro
